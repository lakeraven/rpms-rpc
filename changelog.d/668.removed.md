`Phr.find` is removed; it returned a SNOMED CT term lookup as a CCD document (#668)

- `find(ien)` sent the IEN to `BEHOCIR GETTXT`, which is `GETTXT(RET,SNOMED)`: a SNOMED CT term lookup that answers `TERM^DESCRIPTION_ID` for a concept and `^` for anything else. On bcer-9.0-20261109-d3adcff-ydb it answers `Hypertensive disorder^1215744012` for 38341003 and `^` for an IEN.
- A CCD document is a VistA Imaging image (#2005, type CCD-SUMMARY) whose content is a file on the image store. No RPC the build registers returns it (`BEHOCCD *`, `BEHOCIR *`, `BEHOCIR1 *` and the MAG RPCs were read), so by ADR 0008 the method goes rather than being rebuilt. The `:immunization_text` mapping, its last caller gone, goes with it.

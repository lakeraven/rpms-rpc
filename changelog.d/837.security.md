`Medication.find` answers only a medication on the patient's own list (#837)

- `ORQQPS DETAIL` reads a prescription by its id alone (`OEL^PSOORRL` reads `^PSRX(IFN)` and never compares its patient), so `Medication.find(4, "1R;O")` answered patient 2's prescription on `bcer-9.0-20261119-f67498c-ydb`, the first release that seeds one.
- `find` now lists the patient's medications first (`ORQQPS LIST` from FileMan date 1, the whole history) and sends `ORQQPS DETAIL` only for an id on that list. An id the list does not give answers nil, with only the list sent. Each call now sends two RPCs.
- Proven live as PROV123 on that release (`test/live/medication_detail_live_test.rb`) and on its captured replies (`medication-detail.yml`, recaptured there).

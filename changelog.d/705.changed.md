`Coverage.add_medicaid` requires `number:` and `state_ien:` (#705)

- Both are required keywords, and a blank one raises `ArgumentError` naming it before anything is sent. The registration GUI's Medicaid window requires the number and the state, and the data dictionary requires STATE (`^DD(9000004,.04,0)` is `STATE^RP5'I`). A record filed without a state cannot be indexed: the eligibility row's `AA` cross-reference subscripts by it, so IRIS refuses the null subscript and `UPD^AGGUPMCD`'s trap answers no data row (`:eligibility_failed`, "coverage reply carried no data record"), leaving a header with no eligibility.
- Proven on IRIS for Health Community 2026.2 (bcer-9.0-20261109-d3adcff-iris) and on YottaDB (bcer-9.0-20261110-55d9e3e-ydb, with its region set to refuse null subscripts and as shipped).

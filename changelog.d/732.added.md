`Lab.results` reads a patient's resulted lab specimens for a date range (#732)

- `Lab.results(dfn, from:, to: Date.today)` returns each resulted specimen collected in the range, newest first: the `Lab.specimen` hash (area, collected_at, specimen, accession, provider, and tests with name, value, flag, units, range and LOINC where the build holds one) plus `released_at:` and `status:` (`:final` once released, `:pending` when the report has no released date).
- It steps `ORWLRR INTERIMG` older one specimen per call, the way the Labs tab's Most Recent view does, and stops at the first specimen before `from`. A specimen with no DATE REPORT COMPLETED is not listed, as the routine skips it. A reply that does not step older raises `Client::RpcError`.
- `GET /patients/{dfn}/labs/results` returns the same rows.
- Its tests replay replies captured on `bcer-9.0-20261116-2a9b3fe-ydb` (`lab-results.yml`), on synthetic lab data the capture setup files for one demo patient, and the lab live spec checks each listed specimen against LAB DATA (#63.04).

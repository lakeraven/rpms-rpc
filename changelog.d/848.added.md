`rake report:daily` hands each persona its electronic signature code (#848)

- An optional `<PERSONA>_ESIG` (for the physician, `PMD123_ESIG`) is placed in `RPMS_ESIG` inside that persona's `rake test:live` child only, so signing and releasing an order (`ORWU VALIDSIG`, `ORWDX SEND`) is proven in the daily report instead of skipping.
- The code is scrubbed from the summary, the report and every suite log, like a verify code. A blank or missing one is not handed over, and the persona still runs.
- The order-check live spec now orders the drug of an active prescription again for the same patient, sends USID^ORWDXC the DRUG (#50) IEN it reads, and asserts the duplicate-drug check (#847). An empty reply still fails as unknown, never as "no problems".

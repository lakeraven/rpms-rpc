`Phr.for_patient` sends `BEHOCIR1 GETCCDS` the patient and the date range as three FileMan-date parameters (#698)

`GETCCDS^BEHOCIR1` takes `DFN, STRTDT, ENDDT` as three formals and hands the dates to VistA Imaging's `GETIMGS^MAGSIXG1`. The gem sent one `"DFN^MM/DD/YYYY^MM/DD/YYYY"` parameter. It now sends three, with FileMan dates.
`MAGSIXG1` is not in the FOIA release, so a build without VistA Imaging answers an M error for any frame; `for_patient` raises it as `Client::RpcMError`. The CCD row layout is still unproven: no build has answered one.

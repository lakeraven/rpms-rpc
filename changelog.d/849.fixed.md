`CiaClient#authenticate` names a user who has a nickname, from the server's own answer instead of the greeting (#849)

- `signon_user` and `authenticate`'s `user:` are now the NEW PERSON name (file 200, field .01) that `CIAVCXUS VIMINFO` answers in piece 2. Sign-on already makes that call for the DUZ, so no round trip is added.
- They were read from the sign-on greeting, and Kernel greets a user with a NICK NAME by the nickname: PROVIDER,TEST is greeted "Good morning TEST", so its name came back nil. Users without a nickname get the same name as before.
- A refused or half-bound sign-on still leaves `signon_user` nil.

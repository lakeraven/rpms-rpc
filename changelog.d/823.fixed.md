`Order.action_text` sends the one actual `ACTXT^ORWOR` takes (#823)

`Order.action_text(order_ien)` takes the order alone and sends `IFN;0`, the frame
that lists every action on the order (ORWOR.m:139-144). It sent a second actual,
the action code, and every call died in M with ACTLSTTOOLONG. The build registers
ORWOR ACTION TEXT as ARRAY while ACTXT answers a global name, so the reply has no
lines and the method returns nil; a live spec as PROFILE,MD on the seeded order
proves both. `order_test.rb` replays captured replies for `result`,
`action_text` and `all_sheets` instead of MockClient seeds, and `all_sheets` is
documented as what TSALL^ORWOR lists: the site's treating specialties.

The wire character set is settled by live reads: stored bytes, untranscoded (#476)

- A stored `0xB7` bullet in `#8994` XWB CREATE CONTEXT's description arrives as that one byte over CIA and over BMX on `bcer-9.0-20261109-d3adcff-ydb`, never as the UTF-8 pair `C2 B7`.
- The raw replies are committed in `test/fixtures/wire_charset/`; `wire_charset_test.rb` runs them through each client, and a live spec per transport reads them again.
- The decoding rule is unchanged: a reply is read as UTF-8, and a byte that is not is replaced and reported as altered. `Reply` and the README say so in place of "assumed UTF-8, unproven". XWB on IRIS is not read yet.

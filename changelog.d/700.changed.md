Wire capture names fixtures per catalog entry (#700)

A `CatalogEntry` may carry its own `fixture:` name (default: the RPC slug), so two entries calling one RPC no longer overwrite each other's fixture. `ONLY` matches an RPC or fixture name, `CITE_ONLY` matches a fixture name (or an RPC name for the slug entry) and aborts before any call on an unmatched token, and `wire:compare` reports one row per fixture. `UNKNOWN` joins the evidence placeholders.

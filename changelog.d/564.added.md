`WireCapture` records a TIU progress-note write on the owned loopback rung (#564)

- Catalog entries for TIU CREATE RECORD, TIU LOCK RECORD, TIU SET DOCUMENT TEXT, TIU GET RECORD TEXT, TIU UNLOCK RECORD, and TIU SIGN RECORD are `mode: :write`. They are not `live?`, so a read capture never calls them.
- `WRITES=1` runs create, lock, set text, read-back, unlock, and — when `RPMS_ESIG` is a non-blank string — sign, through `ProgressNote` and `ESignature`. The signature code stays in the driver environment and is stored as `[signature code withheld]`.
- The run is refused before a connection unless the broker host is loopback and `CONTAINER=rpms-ydb-9.0`. A reply the public API does not accept does not replace an existing fixture.

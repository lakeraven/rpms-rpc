### Fixed — the release live guard finds summaries in any directory and ignores editor junk (#600)

- `LIVE_SUMMARY_DIR` naming a directory with `[ ] * ? { }` is no longer read as a glob pattern, so a green summary there is found by `release:live_guard`.
- `suite_fingerprint` skips dotfiles, `name~` backups and `#name#` files under `test/live/`, so an editor swap file no longer voids a green live run. Real specs, helpers and the coverage config still count.
- This change edits `lib/rpms_rpc/live_summary.rb`, which the gem ships, so `source_fingerprint` changes too. Every live summary written before this change is rejected by the guard: run `rake test:live` again to get a fresh summary before the next release.

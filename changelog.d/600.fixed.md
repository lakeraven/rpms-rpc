### Fixed — the release live guard finds summaries in any directory and ignores editor junk (#600)

- `LIVE_SUMMARY_DIR` naming a directory with `[ ] * ? { }` is no longer read as a glob pattern, so a green summary there is found by `release:live_guard`.
- `suite_fingerprint` skips dotfiles, `name~` backups and `#name#` files under `test/live/`, so an editor swap file no longer voids a green live run. Real specs, helpers and the coverage config still count. Summaries written before this change need `rake test:live` re-run only if a junk file was in the tree when they were written.

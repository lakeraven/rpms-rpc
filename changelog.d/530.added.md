`SchedulingSetup.creates_visit_at_checkin` reads whether check-in creates the PCC visit (#530)

- `creates_visit_at_checkin(hospital_location_id)` reads BSDX IHS clinic setup (#9009017.2) field .09 CREATE VISIT AT CHECK-IN with `DDR GETS ENTRY DATA` in `CIAV VUECENTRIC`. `CHECKIN^BSDX25` (`BSDX CHECKIN APPOINTMENT`) creates the PCC visit through `GETVISIT^BSDAPI4` only when that flag's internal value is `1`.
- The read is fail-closed. An IEN that is not a positive integer returns nil and sends no RPC. A nil reply or an error reply raises `Client::RpcError` rather than answering false. Any other value, including a clinic with no #9009017.2 entry, is false.

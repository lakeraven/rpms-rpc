`MockClient`, `MockFhirClient`, `RpmsRpc.mock!` and `RpmsRpc.mock_fhir!` are gone: the gem ships no fake of RPMS (#624, closes #362) — **breaking**

- **Breaking.** `RpmsRpc::MockClient`, `RpmsRpc::MockFhirClient`, `RpmsRpc.mock!` and `RpmsRpc.mock_fhir!` are deleted, with `require "rpms_rpc/mock_client"` and `require "rpms_rpc/mock_fhir_client"`. The fake answered whatever a test seeded, in the shape its author believed RPMS has, and nothing checked that belief against the pinned build (ADR 0010, "The in-memory fake").
- **Breaking.** The `DataMapper` formatting that only seeded the fake is deleted: `Mapping#format_one`, `#format_many`, `#format_scalar`, the private `#format_value`, and the `format_row` mapping hook (with the one `format_row` on the problem-list mapping). Parsing is unchanged.
- What a host does instead (ADR 0010, host rule 3): its unit tests replace the host's own adapter layer with a double of its own design, and do not fake RPMS; its integration tests run against a container of the pinned build. No migration path is provided. lakeraven-ehr's move off the fake is https://github.com/lakeraven/lakeraven-ehr/issues/1207.
- `ClinicalEvent`'s served-RPC check asks the client directly: every broker client answers `served_rpcs` (or raises, which still lets the call run), so the branch for a client without it, which only the fake took, is gone.
- `RpmsRpc.client` and `RpmsRpc.fhir_client` no longer suggest `mock!` / `mock_fhir!` when nothing is configured. `FhirClient` itself is unchanged; its removal is #360.
- `rake rpc:coverage` and `rake rpc:api_coverage` no longer special-case `lib/rpms_rpc/mock_client.rb`.
- This removal supersedes the `MockClient` additions noted earlier in this release (#456, #521): those methods are gone with the class.

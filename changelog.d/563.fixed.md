`Encounter.open` no longer lists a component as missing when `BEHOENCX CHKVISIT` reports it present (#563)

- `:missing_components` keeps a CHKVISIT row unless its message, stripped of surrounding whitespace, is exactly `Visit has POV`, `Visit has E&M code`, `E&M code not required.` or `Provider does not require E&M code`. A nil message stays, and so does every other text.

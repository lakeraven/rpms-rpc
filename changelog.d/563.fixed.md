`Encounter.open` no longer lists a component as missing when `BEHOENCX CHKVISIT` reports it present (#563)

- When both checks are reported, `:missing_components` keeps a CHKVISIT row unless its message, stripped of surrounding whitespace, is a satisfied text of that row's own component: `Visit has POV` for POV, or `Visit has E&M code`, `E&M code not required.` or `Provider does not require E&M code` for E&M. A nil message stays, and so does every other text.
- `:missing_components` is nil when CHKVISIT does not report both checks.
- A satisfied text counts only for its own component.
- `Encounter.open` is now `non_idempotent_write` in retry safety because CHKVISIT can file an alert.

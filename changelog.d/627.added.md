`Agg.update_legal_names` edits or deletes a patient's LEGAL NAME row (#627)

`Agg.update_legal_names` wraps `AGG UPDATE LEGAL NAMES` (`LEGL^AGGPTNAM`) for an existing file 9000033 row: it checks the row's `.02` is the patient before the write, sends one allowlisted parameter per edit, and refuses a blank-RIEN add, which is left for a later change.

`Agg.update_legal_names` edits or deletes a patient's LEGAL NAME row (#627)

`Agg.update_legal_names` wraps `AGG UPDATE LEGAL NAMES` (`LEGL^AGGPTNAM`) for an existing file 9000033 row: it checks, on one clean read, that the row's `.02` is the patient before the write, sends exactly one of `AGGLNDTC`, `AGGLNMC`, `AGGLNPRF` (a #9000030 IEN) or `AGGLGDOC` per edit, and refuses values LEGL would file wrongly (`@`, `^`, control characters, surrounding whitespace, out-of-range lengths, and dates outside 1800-2699). A failure reply after the write is sent says `written: :unknown`. A blank-RIEN add is refused, left for a later change.

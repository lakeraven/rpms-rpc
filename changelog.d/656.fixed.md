`Immunization.text_summary` reads the patient's Immunization Profile (#656)

- `text_summary(dfn)` now sends the DFN to `BGOVIMM PROFILE` (PROFILE^BGOVIMM2 -> IMMPROF^BIRPC), the profile text VueCentric's immunization component shows, and returns its lines as one String. It used to send the DFN to `BEHOCIR GETTXT`, a SNOMED CT term lookup that answered `^` for every patient.
- A patient not in the Immunization Register gets the package's message saying so. A package error (for example error 307, no profile produced, on a build without the ImmServe forecaster) raises `RpcError` and is never returned as a summary.
- Proven live on a throwaway container of bcer-9.0-20261109-d3adcff-ydb (`test/live/immunization_profile_live_test.rb`), with the replies pinned as captures.

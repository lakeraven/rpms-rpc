Clinic-user membership reads retain every user across pages (#771, lakeraven-ehr#984)

`SchedulingSetup.resource_users` traverses BSDX RESOURCE USER by unique record
number rather than its repeated resource pointer, so a 100-row page boundary
cannot omit later members of the same resource. Returned users remain sorted by
name. Synthetic wire regressions cover 100, 101 and 205 members. Live on a
disposable bcer-9.0-20261116-2a9b3fe-ydb container with 205 members on one
resource, the read returned 100 before and 205 after.

`rake openapi:pin` pins a release whose rpcs.json names a short build commit, and reads the release over REST (#639)

rpms-ops's rpcs.v2 header records the build commit as 7 to 40 hex characters. `openapi:pin` now resolves it to the full commit `rake conformance:pin` already verified for the tag in `data/fingerprints/rpms-ops.lock.yml`, and refuses when the lock does not pin the tag or disagrees, so run `conformance:pin` first. The release and its asset are read with `gh api` (REST) instead of `gh release`, and only a published release (not a draft or prerelease) is pinned.

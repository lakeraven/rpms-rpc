A session can find the RPMS broker already starting (#730)

A SessionStart hook, `bin/factory_live_rpms`, starts the pinned release in the background when the environment sets `FACTORY_LIVE_RPMS=1`. Elsewhere it does nothing. A broker already answering on 127.0.0.1:9100 is left alone, one run holds the lock at a time, and a failed run is retried only after a backoff that doubles per failure.

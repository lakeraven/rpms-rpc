`Coverage.add_private_insurance` refuses an insurer AG does not list, before anything is written (#691)

`UPD^AGGUPPVT` files the insurer pointer as given, and every later read of the patient's Private Insurance window then died on it, so `Coverage.on_file` timed out for that patient.
The gem now reads AG's insurer list (`AGG GET INSURANCE DATA`) first: an insurer not on it returns `{ success: false, error: :insurer_not_on_file }`, and a list that does not answer returns `:verification_failed`. Neither sends the write.

The registration-record live spec registers with an SSN no patient holds (#853)

- `test/live/patient_registration_record_live_test.rb` drew a random SSN and never checked it, so a run on a container that already held earlier runs' patients could fail with "SSN already used by another patient."
- It now draws through `fresh_ssn`, which asks AG's own SSN check (AGG WINDOW DATA VALIDATION) until a draw is free, at most 10 tries, and fails listing every SSN it tried. The check moved to `test/live/free_ssn.rb`, shared with the duplicate-SSN spec that got it in #810.

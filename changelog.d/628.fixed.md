`RpmsRpc::Features` refuses a malformed lock tag and a context that is not a non-empty String with ArgumentError (#628)

- A lock file that is a bare scalar raised IndexError from `available?`; any failure reading the lock is now "lock file is malformed", naming the path.
- The sole pinned tag is held to the same tag-name rule as a passed `build:`. A key that is not a String raised TypeError, and a key such as `../<tag>` named a directory outside `data/inventories`.
- `context: ""`, a Symbol or any other non-String answered false on `available?` and was skipped on `for`; both now raise ArgumentError, as `context: nil` already did.
- The out-of-order LIMIT note now says where the complete set lives: openrpms publishes it as field 7 of `<tag>-rpc_reach.txt`, which `<tag>-rpcs.json` does not carry yet (lakeraven/openrpms#1266).

Behavioral Health AMHG reads over CIA no longer return the recordset header as a record (#673)

- `BehavioralHealth::Wire#rows` and `#text_lines` now split the GLOBAL ARRAY frame (sequence echo, `\x00` ack, `$C(30)`-separated rows, `$C(31)`) before parsing, as `BehavioralHealth.visits` already did. Before, over CIA, `Reference.patients`, `Reference.site_parameters`, `Intake.intakes`, the Groups and CaseManagement reads and the visit detail readers parsed the typed header, with the sequence echo on it, as a record.
- `CapturedReplies::ReplayCiaClient` replays GLOBAL ARRAY reads through `CiaClient`'s own reply handling (`CiaClient#global_array_reply`, extracted from `#call_rpc_global_array`).
- Proven on replies captured from a throwaway container of bcer-9.0-20261109-d3adcff-ydb and by `test/live/behavioral_health_reference_live_test.rb`.

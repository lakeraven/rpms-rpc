`Registration.race_ethnicity` returns each race and ethnicity's HL7 value (#830)

- Each row of `:races` and `:ethnicities` carries `hl7_value:`, the code file's 3 HL7 VALUE (`#10` for a race, `#10.2` for an ethnicity): the CDC Race & Ethnicity code a FHIR or HL7 v2 caller codes the entry with, for example `"1002-5"` for AMERICAN INDIAN OR ALASKA NATIVE and `"2186-5"` for NOT HISPANIC OR LATINO.
- It is `nil` when the code entry has none, as the build's inactive legacy races do; it is never guessed from the name. A failed code-file read raises `Client::RpcError`, as the rest of the read does.
- `GET /patients/{dfn}/registrations/race-ethnicity` returns the same rows, so it gains the key too. No other method's return changes.
- The read sends one `DDR GETS ENTRY DATA` per row on file. Its tests replay replies captured on `bcer-9.0-20261116-2a9b3fe-ydb` (`registration-race-ethnicity.yml`), and the registration-edits live spec reads the codes back.

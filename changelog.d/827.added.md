`rake rpc:inventory_clients` rewrites the RPC inventory's client lists from their sources (#827)

`CLOUD_RPMS=`, `OPENRPMS=` and `LAKERAVEN_EHR=` checkouts and `BPRM_XML=` give the VueCentric recordings, the names
the released client carries, the methods lakeraven-ehr calls and the entry points BPRM's stored procedures call.
Each snapshot's header names the repository and commit, or the file and its sha256. A missing, wrong or dirty
source fails with EXPLICIT FAILURE and leaves every snapshot as it was.
- `bprm-entry-points.txt` replaces `bprm.txt`: it keeps the entry points, and the inventory matches them to each
  release's registered entry points.

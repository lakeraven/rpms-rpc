The RPC inventory is a release asset, with the reviewed exclusion and VueCentric call counts as columns (#826)

`rpc-inventory-release.yml` attaches `rpc-inventory.csv` and `rpc-inventory.md` to each published release, proves
the uploaded bytes, and adds an "RPC inventory" section to the notes: both openrpms tags, the command that writes the
same bytes, and the columns against the previous release that carries the CSV.
- `excluded`: the reviewed `gui_plumbing` or `write_needs_fixture` reason from `data/rpc_coverage/exclusions.yml`,
  kept when a wrapper sends the RPC anyway; the Markdown summary names those.
- `vuecentric_calls`, `vuecentric_sessions`: the calls summed over the recorded VueCentric sessions, and how many
  sessions called it. `data/rpc_inventory/clients/vuecentric-observed.tsv` replaces the `.txt` and keeps a count
  per recording.

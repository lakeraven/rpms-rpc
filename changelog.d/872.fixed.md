`Problem.lex_search`, `audit_history` and `comments` read the rows the build sends (#872)

- `lex_search(text)` answers `{ ien:, description:, code:, code_ien:, coding_system: }` per Lexicon match: `ien` is the Lexicon entry, and `code` is the ICD code only when the build sends one (it used to be the Lexicon IEN). The last line, the match count, is not a row.
- `audit_history(ien)` answers `{ date:, text: }` per change, the date as the build prints it (`"11/20/26"`). The count line and `NONE` are not rows (they used to come back as rows, with each date in `:event`).
- `comments(ien)` answers `{ comment: }` per active note (the text used to land in `:date` and be lost).

Tribal enrollment reads are captured live on the pinned build (#566)

- `WireCapture::CatalogEntry` takes an optional fixture name. `fixture_name` is that name, or the RPC slug when it is omitted, so existing captures keep their file names. `WireCapture.fixture_path` writes `test/fixtures/wire_captures/<fixture_name>.yml`.
- `rake wire:capture` keys the driver reply and the fixture lookup by fixture name, and `ONLY` / `CITE_ONLY` match either the RPC name or the fixture name. The driver still calls reads only.
- Eight tribal DDR reads (enrollment, eligibility, tribe, service unit, tribe list, community list, and both validator outcomes) are catalogued with the parameters `Tribal` sends and were captured as PROV123. `docs/pilot_rpc_readiness.md` grades each Tribal method from those captures, and records the Eligibility-window write.
